# Flutter QR Scanner App

Un proyecto de flutter que escanea un codigo QR con la camara del movil , lo guarda en una base de datos local sqlite y redirecciona a ubicaciones o links. \
La lista permite guardar links de tipo https y de tipo geo en un widget tipo dismissable que permite borrar los registros guardados\
Demuestra el uso y el comprendimiento básico de un mapa Google Maps dentro de la misma aplicacion mediante peticiones asincronas asi como tambien el uso de Futures, utilizando el gestor de estado Provider.

**Realizado en el curso de [Fernando Herrera](https://fernando-herrera.com/) de en [Udemy](https://www.udemy.com/course/flutter-ios-android-fernando-herrera/) , SECCION #10**
